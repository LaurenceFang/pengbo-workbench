# Pengbo Workbench v0.1.0

This is the first local-first Windows desktop pre-release for external review.

## Included Artifacts

- `pengbo-workbench.exe`
- `Pengbo Workbench_0.1.0_x64_en-US.msi`
- `Pengbo Workbench_0.1.0_x64-setup.exe`

## Reviewer Scope

- Local Tauri desktop shell with FastAPI sidecar.
- No-key demo startup path.
- Research briefs with structured decision review and evidence-pack export.
- Read-only Data Sources report export with provider health, freshness, provenance, and safety boundaries.
- Strategy backtest and paper-session exports with simulated evidence labels.
- Local security, loopback sidecar, and no live-trading-by-default boundaries remain in place.

## Boundaries

- Unsigned Windows pre-release.
- No hosted service, remote account system, public API, auto-update channel, or live order submission flow is enabled by this release.
- Uploaded artifacts must exclude runtime data, logs, diagnostics bundles, Stronghold vaults, provider credentials, unlock secrets, session tokens, SQLite/DuckDB databases, and private local state.

## Validation

Release validation is tracked in `docs/RELEASE_CHECKLIST.md` and `IMPLEMENTATION_TASKS.md`.
