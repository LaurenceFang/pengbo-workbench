## Purpose

T96 turns the selected T96-T195 backlog into a reviewable Figma roadmap for the
v0.1.0 to v1.0 product arc. It is a design-planning artifact only: it must not
change runtime behavior, provider contracts, security boundaries, packaging, or
live-trading scope.

## Required Frames

The roadmap should contain these editable Figma frames:

1. `00 Cover`
   - Product name and v0.1 to v1.0 roadmap title.
   - Local-first boundary statement.
   - Explicit note that hosted accounts, public APIs, remote sync, and new live
     trading are not introduced by T96.
2. `01 Roadmap Overview`
   - Horizontal milestone flow from UI foundation to commercial proof.
   - Lanes for Product, UI, AI, Data, Quant, Workflows, Release, Safety, and
     Commercial.
   - Every task from T96 through T195 mapped to a lane or milestone.
3. `02 Execution Order`
   - Batch 1: T96-T115.
   - Batch 2: T116-T135.
   - Batch 3: T146-T165.
   - Batch 4: T136-T145 plus T166-T175.
   - Batch 5: T176-T195.
4. `03 First Batch Detail`
   - Expanded T96-T115 cards.
   - Clear handoff from T96 into T97, T98, T99, T100, and T107-T115.
5. `04 Design Principles`
   - Local-first desktop.
   - Evidence-backed research.
   - Chinese-first copy with English support.
   - Professional financial tool density.
   - No-secret visual assets.
   - AI output must cite evidence or enter limited or blocked states.
